# Criação de Projeto Python 

Script para automatizar a criação de projetos Python.

## Funcionalidades

#### O script cria automaticamente:
* Estrutura inicial do projeto
* Ambiente virtual ativo (`venv`)
* Pastas 
* Arquivo `README.md`, `requirements.txt` e `.gitignore`
* Arquivo inicial main.py

## Tecnologias

- Bash 
- Python 
- Linux
- Vscode

## Como executar
```bash
chmod +x criar_python.sh
./criar_python.sh
```
